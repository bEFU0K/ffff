# GFPGRAM: статус функций из списка

Готово (патчи, не проверены сборкой):
- Ghost Mode: прочитано, онлайн, набор текста/запись голосовых/загрузка медиа (общий канал активности), сторис, скриншоты, прослушано
- Anti-Recall: сохранение удалённых и очищенных чатов, запись истории правок (просмотра нет)
- Реклама: скрытие спонсорских сообщений
- Копирование из закрытых каналов, ID/DC/страна в профиле (профиль отключён по умолчанию)
- Название GFPGRAM, иконка, «Владелец» -> «#»

Нужен интерфейс (нужен точный код экранов, после первой сборки):
- Экран настроек со всеми переключателями, просмотр удалённых и истории правок
- Message Shot, Streamer Mode, подтверждение отправки, шрифты, ширина сообщений, скругление стикеров
- Скрытие похожих каналов, счётчиков папок, папки «Все чаты», «прочитать все»
- Перевод, список недавних стикеров, время реакций

Не получится: настоящий Premium и его серверные функции (только визуальная имитация у себя).
