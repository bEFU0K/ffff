# GFPGRAM: что есть в клиенте

Где что находится:
- Кнопка 👻 — справа в шапке списка чатов (включает/выключает режим призрака целиком).
- Меню GFPGRAM — Настройки → самая верхняя строка «GFPGRAM» (все переключатели).
- Смена иконки — Настройки → GFPGRAM → «Иконка приложения» (3 своих иконки идут первыми).
- Админ-панель — Настройки → GFPGRAM → «О GFPGRAM» → ввести ключ. После первого входа появляется отдельная строка «Админ-панель».

Функции:
- Режим призрака: не читать, не печатает, не «в сети», истории, скриншоты, «прослушано».
- Режим «шпион»: удалённые собеседником сообщения остаются с маркером 🗑, изменённые — с ✏️ (история правок хранится на устройстве). Чат, где удалена вся переписка, в списке чатов помечен 🗑 и серым.
- Обход ограничений: пересылка/копирование/сохранение в закрытых чатах и каналах.
- Скрытие рекламы, сохранение очищенных и самоудаляющихся сообщений.
- Админ-панель: значок «#» рядом с именем пользователя/канала по @username (виден только на этом устройстве).

Ограничения:
- Значок «#» локальный: другие пользователи его не увидят.
- Защита от скриншотов в закрытых каналах снимается настройкой «обход», но системный запрет iOS на запись экрана для DRM-контента не обходится.
- Настоящий Premium и его серверные функции недоступны.
- Код не проверен сборкой Xcode: первая сборка может показать ошибки компиляции.
